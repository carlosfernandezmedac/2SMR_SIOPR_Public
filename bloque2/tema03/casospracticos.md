# Casos Prácticos — 3. Instalación y explotación básica de SO de servidor propietarios

---

## Caso Práctico 1 — Preparación de la instalación

**Planteamiento:** antes de instalar un sistema operativo hay que seguir unos pasos previos para que la instalación se haga correctamente.

**Nudo:** enumera y describe los pasos para preparar la instalación de Windows Server.

<details>
<summary>💡 Ver solución</summary>

1. **Elegir la versión** de Windows Server (en nuestro caso, 2019).
2. **Elegir la edición**, según el número de usuarios, el tamaño de la empresa y si se va a virtualizar: Essentials, Standard o Datacenter.
3. **Comprobar los requisitos de hardware**, consultando la página oficial de Microsoft para esa versión (procesador, RAM, disco, red).
4. **Decidir el particionado**: una partición para el sistema operativo y otra para los datos, formateadas en NTFS.

</details>

## Caso Práctico 2 — Instalación de Windows Server 2019

**Planteamiento:** en este tema hemos visto los pasos para instalar Windows Server 2019.

**Nudo:** seguir esos pasos e instalar el sistema operativo para que pueda usarse.

<details>
<summary>💡 Ver solución</summary>

✅ **Este caso ya lo resolvisteis en la práctica del Tema 2:** creasteis la máquina virtual, elegisteis la edición **"Windows Server 2019 Standard Evaluation (experiencia de escritorio)"**, aceptasteis la licencia, elegisteis instalación **"Personalizada: instalar solo Windows"**, particionasteis el disco, instalasteis el sistema y accedisteis por primera vez con `Ctrl+Alt+Supr` y la contraseña del usuario **Administrador**.


</details>
