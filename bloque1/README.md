## ¿Qué vamos a ver en este bloque?

```
Tema 1  ──►  El punto de partida     → qué es un SO en red, cliente/servidor, qué sistemas hay
                                       y cómo comprobar los requisitos de un equipo
Tema 2  ──►  Preparar la instalación → particiones, sistemas de archivos, gestores de arranque,
                                       instalación atendida y desatendida, imágenes,
                                       virtualización e instalación en red
```

Primero entendemos **qué es un sistema operativo en red** y cómo elegir el más adecuado según el contexto; después aprendemos **cómo se prepara y se lleva a cabo una instalación**. Es la base para los bloques siguientes, donde instalaremos y administraremos Windows Server y Ubuntu Server en máquinas virtuales.
